# ComfyUI Grok Image Describer

A custom node that uses the Grok API (xAI) to describe input images based on freeform instructions. Perfect for generating high-quality prompts for image-to-video models (Wan, etc.).

## Installation

1. Via ComfyUI Manager: Search for "grok describe" or install via git URL.
2. Manual:
   ```bash
   cd ComfyUI/custom_nodes
   git clone https://github.com/IxalonDarkstone/comfyui-grok-describe.git
   cd comfyui-grok-describe
   pip install -r requirements.txt
